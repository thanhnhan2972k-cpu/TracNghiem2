# Cách nạp đề

Bạn chỉ cần đặt file đề vào thư mục này rồi commit/push lên GitHub.

Hỗ trợ:
- `.txt`
- `.docx` (văn bản thật, không phải ảnh scan)
- `.pdf` có lớp text
- `.json`

## Mẫu TXT / DOCX / PDF text

TITLE: Tên bài
DESCRIPTION: Mô tả
SUBJECT: Toán học
ICON: 🧮
DURATION: 5

Câu 1: Nội dung câu hỏi?
A. Lựa chọn A
B. Lựa chọn B
C. Lựa chọn C
D. Lựa chọn D
Đáp án: B
Giải thích: Nội dung giải thích tùy chọn.

`DURATION` tính theo phút.

PDF scan chỉ chứa hình ảnh hiện chưa được OCR.
